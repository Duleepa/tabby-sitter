Tabby Sitter

New rule

Domain: one hostname per pattern, e.g. github.com. Matches that host and its subdomains (not notgithub.com); a leading www. is ignored.

Sync file

Keep rules, settings and saved groups in step across computers with a file in a folder you already sync. Tabby Sitter never uploads anything. Your sync service copies the file; see Help.

This browser does not support linking a file.

How to sync between computers

Disclaimer. Tabby Sitter only reads and writes a local file that you pick. Any copying of that file between computers is done by your own sync service (Dropbox, iCloud Drive, Google Drive, OneDrive, Syncthing, an Obsidian vault, etc.). Tabby Sitter is not responsible for that sharing: where the file is stored, who can access it, or how it is backed up. The file contains your rules and the URLs of your saved groups, so only keep it in a location you trust.

Steps.

  1. Machine 1: click “Create sync file…” and save it inside a synced folder.
  2. Wait for your sync service to copy the file to machine 2.
  3. Machine 2: click “Link existing file…” and pick the same file.
  4. After restarting Chrome, click “Reconnect” so Chrome can access the file again.

Where to put the file.

  • Dropbox: create the file inside your Dropbox folder, e.g. ~/Dropbox/tabby-sitter.conf.json.
  • iCloud Drive: choose “iCloud Drive” in the picker (on macOS ~/Library/Mobile Documents/com~apple~CloudDocs). “Optimise Mac Storage” may evict the file; keep it downloaded.
  • Google Drive / OneDrive desktop apps: use the synced folder and mark the file “available offline”.
  • Obsidian vault: put the file in the vault folder (synced by Obsidian Sync, iCloud or git). With Obsidian Sync, turn on “Sync all other types” in its settings, otherwise .json files are not synced. Obsidian does not list .json files, so it won’t clutter your notes.
  • Syncthing or any other folder sync works the same way.

Several Chrome profiles? Each profile has its own copy of the extension, with its own rules, saved groups and linked file. Set a profile name above and “Create sync file…” suggests a matching file name (it stays on this profile and is never written to the file). Give each profile its own file (e.g. tabby-sitter-work.conf.json and tabby-sitter-personal.conf.json) to keep their setups separate, or link the same file in several profiles to share one setup.

Tip. Avoid editing on two machines at the same time. If the “Sync file changed on another device” banner appears, choose which side to keep.

Duplicate Tabs

Prevent opening the same URL in multiple tabs.

Tracking parameters (utm_*, fbclid, gclid, and similar) and #fragments are already ignored. A new duplicate tab is closed and you can undo it; a tab you navigate to a duplicate is never closed, only flagged.

Keep tabs in their group

Keep tabs opened from a group in that group when no rule matches them. Rules for a different group still win.

Memory

Unloaded tabs stay in your tab strip and reload when you click them. Unsaved form input in an unloaded tab may be lost. Active, playing-audio and pinned tabs are never unloaded unless you allow pinned tabs.

Domain Sorting

When organizing, tabs that don't match any rule will be sorted alphabetically by domain name.
